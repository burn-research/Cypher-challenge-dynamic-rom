Baselines

A minimal working baseline is provided in sample_code_submission.zip, available from the "Files" tab of this competition. It implements the required model interface (preprocess, fit, predict) with a simple persistence model (the flow state is predicted to stay constant, equal to the initial snapshot, at every future time step) so that you can see how to structure your own submission and how the ingestion program calls your code. It is intentionally not tuned for accuracy: it exists to be extended or replaced, not to be competitive.
