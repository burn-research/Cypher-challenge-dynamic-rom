Dataset: externally forced 2D laminar flame

The data comes from CFD simulations of 2D transient laminar coflow diffusion flames burning a CH4 and N2 mixture in air, with changing inlet velocity. All fields are provided on a common unstructered grid.vtu (pyvista format) and a corresponding xyz.npy file with the coordinates of the grid cells.

The forcing signal φ(t)

The inlet velocity profile is modulated in time by a scalar forcing signal φ(t). The bulk inlet velocity at time t is U(t) = U_base · φ(t). U_base = 0.70 m/s while φ(t) is provided to you explicitly, alongside the flow state, as an additional input at every time step.

Exact definition of φ(t), by signal type

Step

for t < t₀ : φstep(t) = 1
for t ≥ t₀ : φstep(t) = 1 + A

In this dataset t₀ = 0 s for every step simulation, so φ is simply constant and equal to 1 + A over the whole trajectory.

Sine

φsine(t) = 1 + A · sin(2π f t)

Sine sweep (chirp, exponential frequency law)

Let f₀ = 1 Hz, f₁ = 80 Hz, T = 1 s (duration of each leg), k = ln(f₁/f₀). The signal goes 1→80 Hz over [0, T) and 80→1 Hz over [T, 2T], phase-continuous at t = T:

φsweep(t) = 1 + A · sin(ψ(t))

for 0 ≤ t < T : ψ(t) = (2πf₀/k)(ekt − 1)
for T ≤ t ≤ 2T : ψ(t) = ψ(T) + (2πf₁/k)(1 − e−k(t−T))

File format

Every simulation is stored as a folder containing:

  • state.npy — array of shape ( n_cells, n_features, n_timesteps). The cell order is given by grid.vtu/xyz.npy).
  • phi.npy — array of shape (n_timesteps,), the forcing signal value at every time step.

Two shared files describe the spatial mesh: xyz.npy (shape (n_cells, 3), columns x, y, z — cell-center coordinates) and grid.vtu (the raw unstructured mesh, readable with pyvista), in case you want to exploit the spatial structure of the domain (e.g. convolutional architectures). The time step is constant and equal to dt = 2e-3 s in every simulation.
